# 论文精读报告模板（模式 B）

> 使用时按章节填充。每段关键断言后带证据标记：`[E]` 实证 / `[C]` 作者声称但证据不足 / `[I]` 推断（写出推断链）/ `[NR]` 未报告。

## 0. 一句话结论（BLUF）
> 这篇论文解决了什么、可信度如何（高/中/低）、值不值得用。3–5 句话。

- **可信度判断**：高 / 中 / 低 —— 理由一句话
- **是否值得深读/引用**：是 / 否 / 视场景

## 3. 证据审计（核心）
逐条列出作者的主要结论，判定支撑度：

| # | 作者结论 | 支撑证据 | 判定 | 一句话理由 |
|---|---------|---------|------|-----------|
| 1 | | | 支撑/弱支撑/不支撑 | |
| 2 | | | | |

**七项专项检查**：
- [ ] **baseline 公平性**：baseline 是否同预算 / 同 backbone / 同调参？
- [ ] **指标口径**：绝对值还是相对值？是否挑了有利 metric？
- [ ] **数据泄漏**：训练/测试、prompt/评测是否重叠？
- [ ] **显著性**：方差、置信区间、显著性检验是否报告？
- [ ] **消融完备性**：每个贡献点是否单独消融？掉多少？
- [ ] **外部效度**：单一数据集/模型/语言上的结论能否外推？
- [ ] **人类评估**：标注者数量、一致性 κ、是否盲评、筛选与报酬方式？

---

## 4. 复现评估
- **数据需求**：规模、是否公开、预处理难度
- **算力量级**：训练/推理估算（如论文有则 `[E]`，否则 `[NR]`）
- **开源情况**：代码、权重、数据各自状态
- **未披露项**：超参、随机种子、清洗细节、负结果（作者未报告的 setting 往往是失败处）
- **最小可验证实验**：花最少资源验证的核心结论是什么

## 6. 如果我要用这篇论文
- ✅ **可复用**：方法、组件、评测协议、数据集
- ⚠️ **需警惕**：结论适用范围、被夸大的部分、baseline 陷阱
- 🕳️ **缺口**：哪些claim尚待验证、哪些setting未报告
